# Démo mobile FIDELITIZ

Tableau de bord : https://robino4real.github.io/fidelitiz-mobile-test/
Carte de Camille en direct : https://robino4real.github.io/fidelitiz-mobile-test/carte.html
Écran verrouillé simulé : https://robino4real.github.io/fidelitiz-mobile-test/verrouillage.html
Avis NFC : https://robino4real.github.io/fidelitiz-mobile-test/?avis=marcel-republique&source=nfc

Ouvrir la carte sur un second téléphone et scanner son QR code avec le tableau de bord. Le solde et les notifications se mettent à jour toutes les 2 secondes. Tous les appareils utilisent la même session de données fictives. L’écran verrouillé est une simulation dans Safari, pas une notification système iOS ou un pass Apple Wallet installé. Le lien « Carte de Camille.png » reste une capture figée de référence.

Camille : FDZ-DEMO-CAMILLE, 340 points initialement. Julien : FDZ-DEMO-JULIEN, 520 points initialement. 1 € = 10 points ; café offert à 500 points. Réinitialiser restaure les données de test.
